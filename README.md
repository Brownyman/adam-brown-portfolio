# Adam Brown Portfolio

A static, responsive portfolio. No build tools, dependencies or server required.

Open `index.html` in a browser. The Home, Projects and Contact pages link directly to each other.

## Personalise

- GitHub and LinkedIn profile links are in `contact.html`; update their URLs if your profiles change.
- Update the biography and services in `index.html` to reflect your experience.
- Replace the coming-soon entries in `projects.html` when projects are ready.
- Colours, typography and responsive layouts are in `styles.css`.
- Update the footer year as needed on all three pages.

The site uses Google Fonts and a workspace photograph hosted by Unsplash, so those assets require an internet connection. All layouts and navigation work without JavaScript.

## Publish

Upload the three HTML files and `styles.css` to any static web host, such as GitHub Pages, Netlify or Cloudflare Pages. Keep all four files in the same directory.

The contact page links to your GitHub and LinkedIn profiles in new tabs. There is no form, backend, analytics or tracking code.
